🌐 Interpoint Compressor Web Sitesi

Freelancer iş olarak aldığım bir firmanın backend içermeyen web sitesi projesidir.

Interpoint Compressor, tamamen saf HTML, CSS, JavaScript ve Bootstrap kullanılarak geliştirilmiş, mobil uyumlu ve kullanıcı dostu bir web sitesidir.

📌 Proje Özellikleri

✅ Statik ve hızlı yapı (Saf HTML, CSS ve JavaScript)  
✅ Tamamen mobil uyumlu & responsive tasarım  
✅ Bootstrap 5 ile modern ve şık arayüz  
✅ Kullanıcı dostu ve erişilebilir  
✅ Görsel ağırlıklı ve interaktif deneyim  
✅ Valve, Compressor Rings gibi teknik sayfalar  
✅ Hafif, optimize ve yüksek performanslı  

🛠 Kullanılan Teknolojiler  

- HTML5 – Yapısal içerik  
- CSS3 – Görsel tasarım  
- JavaScript (Vanilla JS) – Dinamik içerikler ve etkileşim  
- Bootstrap 5 – Responsive ve esnek tasarım
